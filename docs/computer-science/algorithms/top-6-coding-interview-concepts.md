## Concepts
- **Heap:** a tree-based data structure that maintains a specific order (min-heap or max-heap).
- **Sliding Window:** a technique that processes a contiguous sub-segment of data efficiently.
- **Binary Search:** a search algorithm that finds a value in a sorted array by repeatedly halving the search space.
- **DFS/BFS:** Depth-First and Breadth-First search algorithms used for traversing graphs and trees.
