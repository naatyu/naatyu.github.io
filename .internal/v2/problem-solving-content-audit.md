## Corrections and evidence scope

A strict bounded real-valued decrease can continue indefinitely (1/(t+1)); use a well-founded value set or a minimum decrease to prove termination. Independence is not required for finite indicator sums. Ordered conditional arrival times are dependent order statistics, not independent sorted values. A positive rate is required for exponential waits; zero is a no-arrival boundary. A product-rule continuation count must hold for each earlier choice. Information worlds must match the requested answer. Equal chessboard color counts remove one obstruction, not prove a tiling. Units can be correct while a physical model remains wrong.
