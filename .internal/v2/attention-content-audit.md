## Corrections rather than propagated source errors

- Q/K/V are input-dependent activations; WQ/WK/WV are learned parameter matrices.
- Token IDs do not all have identical embeddings. Repeated IDs share initial lookup values, not necessarily contextual states.
- With query rows and key columns, each row normalizes across the key dimension. Columns do not generally sum to one.
- Mask logits before softmax. All-masked rows need an explicit implementation policy.
- The square-root scaling derivation states zero-mean/unit-variance independence assumptions. Uniform probabilities have nonzero Jacobian entries; “uniform means zero gradients” is incorrect.
- Dot products depend on norms and angles. KV caching avoids repeated prefix computation but does not make growing-prefix retrieval constant-time.
- Key/value projection composition is a parameter identity under given shapes; V activations are not the same object as WV.
- Cross-attention can connect sources of the same modality.
- Linear-attention causal matrices need not have the simple global low-rank limitation claimed for an unmasked factorization.
- A bounded per-step KDA decay does not bound reciprocal products over arbitrary sequence length. Chunking and accumulation still matter.
- Sparse attention and bounded replay are not exact dense/full-depth operations, even when quality recovery is strong in reported experiments.
