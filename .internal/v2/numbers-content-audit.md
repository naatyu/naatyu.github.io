## Corrections and limits

- Negative unmasked Python set-bit or shift loops need not terminate. Reject or explicitly mask a finite word. `bit_count` counts the absolute-value representation, not the signed word's ones.
- LCM zero guard handles `(0,0)`; dividing first does not eliminate final-result overflow.
- Fast modular power requires nonnegative exponent and positive modulus. Initialize `1 % mod`, including modulus one. Built-in negative powers require an inverse; the teaching loop does not implement that extension.
- Repeated division of negative digits uses floor semantics; separate the sign. A deterministic unbounded process need not repeat.
- Bitmask membership loses multiplicity. Finite-width operation cost is not an arbitrary-precision constant-cost guarantee.
- Mask-based alignment requires positive power-of-two blocks. Python complement identity alone does not establish that precondition. Dimensions and byte addresses need different units.
- Row-major encoding is not a proof of flattened ordering. Spiral rechecks collapsed edges. Rectangular rotation changes shape; square in-place swaps are not a general rectangular routine.
- Normalized slope merges opposite directions intentionally. Duplicate points are separate. Cross-product turn sign assumes x right/y up, unlike the matrix display's downward row direction. Removing square roots does not make floating-point arithmetic exact.
