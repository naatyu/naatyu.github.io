## Corrections and limits

- Low precision is not one dtype switch. Operand, accumulator, output, storage, optimizer and communication precision need separate contracts.
- Max scaling is a simple policy, not universally optimal. Format variants, subnormal handling, scale conventions, clipping and physical layout matter.
- Current scaling is not categorically infeasible. Historical maxima can miss new spikes and retain an unnecessarily coarse range afterward. 1,024 is a recipe parameter.
- NVFP4 is not “only inference”; its particular scale hierarchy and training techniques are not shared by every FP4 cache. Transposing quantized block data cannot recover original values for a different grouping.
- Attention keeps √dₕ and the mask consistent. Sum-to-one applies to valid, nonempty rows; fully masked rows need a policy.
- Bias requires a specified averaging distribution. Nonnegative probabilities do not prove a universal sign, or that bias is always worse than variance. FP32 sums cannot restore rounded-away operands.
- Stochastic unbiasedness is conditional on representable brackets, unclipped values and correct probabilities. Per-draw mass, correlated errors, later nonlinearities and clipping still matter. Renormalization is nonlinear.
- The BF16 midpoint perturbation is our exact worked example, not an attributed reproduction of Su's inaccessible derivation. Tie parity changes direction.
- STE is a backward surrogate, not the true derivative. Learned scales/clamps require separate choices. Affine ties-to-even round the scaled value before adding the integer zero point; translation across an odd zero point can change a tie.
- The symmetric −7…7 four-bit illustration is not all signed four-bit storage and is not exact Q4_0 packing.
- Gemma's published “Gb” label is flagged rather than silently rewritten to GB. Active sparse weights are not total resident storage. Encoder comparisons change architecture/hardware too; no quantization-only causal speedup is inferred.
- DeepSeek's 890 bytes/token is a combined architecture/precision cache component, not full request memory. Fused traffic arithmetic applies to a component, not all model traffic.
