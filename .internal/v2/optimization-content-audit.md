## Fresh evidence and corrections

Targeted primary checks: PyTorch 2.14 AdamW algorithm and epsilon/decay/bias correction; Keller Jordan Muon README and current implementation polynomial, normalization, Nesterov and aspect-ratio code; microsoft/mup README setup, width scaling, fixed-depth family and scheduler/resume limitations; μTransfer paper abstract/publication. This is not a fresh full-paper/appendix/figure audit. kexue 10542 returned 403, so its full fresh source check remains pending. Other original blogs/model-report primaries were not freshly audited in full. GitHub μP repository currently says archived; no package installation or claim of current maintenance is made.

- A smaller learning rate scales instantaneous update signal/noise together; it does not improve gradient-estimator SNR. Larger independent mean batches lower covariance, not necessarily the magnitude of the mean gradient.
- Adam v is a raw second moment, not covariance or Hessian. Bias correction has a stationary-startup meaning, not universal ratio unbiasedness or a replacement for warmup.
- Global clipping caps gradient norm; only plain SGD directly converts this into ητ update bound. Adam moments/decay change the final update.
- Square-root scaling preserves one-step SGD covariance under assumptions, not SNR or fixed-data cumulative covariance. Linear scaling preserves frozen-gradient fixed-data drift/covariance; neither can be extrapolated past curvature limits.
- Gaussian sign expectation is erf; the original rational expression is approximate. Hessian cross-term positivity and reachable optimum are required for the simplified surge argument.
- Rectangular Muon “matrix sign” is a partial polar factor. The spectral quadratic-penalty solution includes the nuclear-norm multiplier; a normalized constrained direction alone omits it.
- A Taylor iteration approaching the polar factor is not the fast practical quintic. The checked implementation explicitly accepts finite non-unit singular values. Zero stays zero, and rounding/shape/dtype matter.
- Moonlight RMS normalization is conditional on full rank/ideal polar singulars. Its 0.2 coefficient and the checked aspect-ratio scaling are distinct conventions.
- μP's stable base LR does not mean raw hidden-weight Adam LR stays width-independent. The reference divides it by width multiplier. Initialization, groups and output convention belong together.
- Recipe defaults, compute-fit coefficients without units, noise/generalization folklore and warmup fractions are priors/examples, not universal prescriptions.
