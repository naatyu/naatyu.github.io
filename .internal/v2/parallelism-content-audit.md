## Corrections / qualifications

- Adam’s two FP32 moments cost eight bytes; twelve includes a four-byte master weight. Explicit example totals 16 bytes with BF16 parameters and BF16 gradients. No universal optimizer-state formula.
- FSDP and ZeRO-3 are related state strategies, not every implementation’s identical schedule.
- Ring bandwidth does not degrade linearly without bound in rank count; latency/topology still matter. No universal GPU-count/batch threshold.
- SP gathers token rows at the described TP boundary, not missing hidden components of each local token.
- CP retains causal visibility. Separately normalized block outputs cannot simply be averaged.
- Pipeline idle overhead (p−1)/m differs from idle fraction (p−1)/(m+p−1).
- TP/EP network placement is conditional; no universal E/k speed multiplier or all-to-all/all-reduce cost ratio.
- Roofline C/W requires byte/FLOP factors. The mixed mesh formula uses a particular overlapped forward-MLP topology model.
- Asynchronous execution is not proof of achieved overlap.
